🚀 PixVault Service Documentation

1) Setup & Installation

# Clone the repository git clone https://github.com/MtCedarNet/PixVault.git cd PixVault # Create virtual environment python -m venv venv # Activate (Windows) .\venv\Scripts\Activate.ps1 # Install dependencies python -m pip install -r requirements.txt # Create and edit the local configuration Copy-Item config.example.toml config.toml # Run server python -m uvicorn main:app --host 127.0.0.1 --port 7979

Server runs at:

http://localhost:7979

Sign in through the browser, click Admin in the navigation bar, and enter auth.admin_password from config.toml to run maintenance actions.

2) Authentication

Replace the public example passwords and session secret in config.toml. The example uses storage.images_dir = "Gallery": put your photo folders under Gallery beside main.py, or change the path to your own image library. The local configuration file is ignored by Git.

Open PixVault in a browser and sign in with the gallery password. Use the separate admin password on the Admin page for maintenance.

3) Thumbnail Generation

On the Admin page, click Generate missing thumbnails. The page shows progress, completed items, and failures. Run it again after adding images.

📁 Folder Metadata

Folders may be nested at any depth under storage.images_dir. On the Folders page, switch between All folders and Browse folders; breadcrumbs, browser Back, and Esc return to parent directories. A parent with its own images has a View photos button.

Use paths relative to that image directory as keys in data/folders.json and data/tags.json, such as Trips/2026.

To create folder display names, click Admin and then Generate folder names. This overwrites manual edits in data/folders.json, so the page asks for confirmation. After editing names, click Rebuild gallery.

🏷️ Tag Generation

On the Admin page, click Add missing tags to add new image folders to data/tags.json. Edit their tags in that file, then click Rebuild gallery.

📊 Statistics

The Gallery and Folders pages display image and visit counts in the browser.

🌍 Visit Logging

When available, visit logging uses these Cloudflare headers:

CF-IPCountry CF-Connecting-IP

🔄 Cache Rebuild

After adding or removing images, or editing these files, click Admin and then Rebuild gallery:

  • folders.json
  • tags.json

⚠️ Notes

  • Keep the passwords in config.toml private
  • Changes may not reflect until cache rebuild
  • Optimized for Cloudflare Tunnel headers
